These color and elevation maps are designed for use in 3D rendering software. They are created from data assembled by the Lunar Reconnaissance Orbiter camera and laser altimeter instrument teams.

The 2025 color map, available as a full-size float16 EXR file and as 16-bit TIFFs of various sizes. The EXR file is encoded in linear color with slightly more dynamic range, while the sRGB-encoded TIFFs are more broadly supported. The map is centered on 0° longitude.

Two versions of the color map are now available. The newer version (above) was produced in December of 2025 using commercial image processing software. It preserves more of the color and dynamic range of the source data and adds greater detail in the polar regions. The original version (below), produced in 2019, has been used successfully in a number of visualizations.
The color maps were adapted from the [http://wms.lroc.asu.edu/lroc/view_rdr/WAC_HAPKE] Hapke Normalized WAC Mosaic, a composite built by the camera team from over 100,000 WAC (Wide Angle Camera) images. The [https://pds.lroc.asu.edu/data/LRO-L-LROC-5-RDR-V1.0/LROLRC_2001/DATA/MDR/WAC_HAPKE/WAC_HAPKE_README.TXT] readme file provides a technical summary of how the mosaic was constructed along with references to more detailed publications. A less formal introduction to the process is in [https://lroc.im-ldi.com/news/707] this LROC blog post and in [https://lroc.im-ldi.com/news/801] this one.
Both color maps were assembled from three of the seven wavelength bands of the LROC color data, with the 643 nm band representing the red channel, 566 nm the green, and 415 nm the blue. Exposure and white balance were adjusted to more closely match human vision, and small data dropouts at high latitudes were inpainted.
The source data covers the lunar globe from 70°N to 70°S. Because the Moon's axial and orbital tilts are both small, many areas outside these latitudes remain shrouded in shadow, even after thousands of passes by LRO's camera, so they are left out of the LROC mosaic. For these color maps, the missing latitudes were filled in with a lower resolution monochromatic albedo map ( [http://pds-geosciences.wustl.edu/lro/lro-l-lola-3-rdr-v1/lrolol_1xxx/data/lola_gdr/cylindrical/float_img/ldam_10_float.lbl] LDAM) from LRO's laser altimeter, which measures the brightness of the reflected laser. When rendered with realistic shadows, these parts of the map aren't particularly visible, and while they comprise more than 20% of the map's pixels, they represent only 6% of the Moon's surface.
These image is optimized for aesthetics, not science. Scientific applications should use [http://wms.lroc.asu.edu/lroc/view_rdr/WAC_HAPKE] the source data.

The displacement map, at 64, 16, and 4 pixels per degree, centered on 0° longitude. Available as either floating-point TIFFs in kilometers, relative to a radius of 1737.4 km, or unsigned 16-bit TIFFs in half-meters, relative to a radius of 1727400 meters.

The displacement map (also known as a height map or elevation map) was taken directly from the latest (as of spring 2019) gridded data products of the Lunar Orbiter Laser Altimeter instrument team. [http://pds-geosciences.wustl.edu/missions/lro/lola.htm] LOLA data is archived on the Geosciences Node of the Planetary Data System. A small subset of the LOLA data stored there, the global cylindrical projections at 4, 16, and 64 pixels per degree, has been reformatted here as uncompressed TIFF files, in vertical units of either floating-point kilometers or 16-bit unsigned integer half-meters.
The reference surface for all LRO data is a sphere of radius 1737.4 km. LOLA's gridded elevation data is published as signed 16-bit integers in units of half-meters relative to this radius. For the floating-point TIFFs, the source data was divided by 2000. For the unsigned 16-bit TIFFs, the source data was offset by +20,000 (10 km) so that all of the values are positive. This latter format is provided for software that doesn't work well with either floating-point or signed integer files.

This animation illustrates how color and displacement maps are used in 3D animation software to paint and model an object like the Moon.

Within 3D animation software, an object like the Moon begins as a simple geometric shape, in this case a sphere. Texture maps like the ones on this page are used to add detail to the model. The color map tells the software how to paint the surface, and the displacement map tells it how to add the shape details that define the lunar terrain. Without them, the Moon model is just a smooth, monochrome ball. Although these maps are flat rectangles, the software understands them as maps of a spherical surface and knows how to warp them onto spherical geometry.
Each pixel in these texture maps corresponds to a point on the lunar surface defined by a longitude-latitude pair. Pixels in the color map contain the "base color" of the surface, before applying the effects of varying light and camera angles (called incidence angle i and emission angle e in the technical description). Pixels in the displacement map contain the height of the surface at the corresponding locations.

More Data

These maps are a tiny subset of [http://pds-geosciences.wustl.edu/missions/lro/] the data publicly archived by the LRO instrument teams. All of the data is in standard and fairly simple PDS file formats (files with ".IMG" filename extensions). Although not typically supported by general-purpose computer graphics software, these formats are directly readable by some GIS programs. The data formats are documented in PDS labels, which are either separate text files with a ".LBL" filename extension or embedded as fixed-length headers. Other than the possible header, most .IMG files are uncompressed 2D binary arrays of numbers. Some data is also available in TIFF or JPEG2000 formats.
As of this writing, the best global-scale elevation data for equatorial and mid-latitude regions of the Moon, at resolutions up to 512 pixels per degree, is [http://pds-geosciences.wustl.edu/lro/lro-l-lola-3-rdr-v1/lrolol_1xxx/data/sldem2015/] SLDEM2015. For regions near the poles, where the density of laser shots is much higher, the [http://pds-geosciences.wustl.edu/lro/lro-l-lola-3-rdr-v1/lrolol_1xxx/data/lola_gdr/polar/] GDR data in polar stereo projection reaches resolutions of five meters per pixel.
The LROC narrow-angle camera (NAC) has imaged most of the Moon's surface at a resolution of one meter per pixel or better. LROC imagery can be explored graphically using its [https://quickmap.lroc.asu.edu] Quickmap interface and searched on its [http://wms.lroc.asu.edu/lroc/rdr_product_select] RDR Product Select page. Of particular interest are the Topographic Products (menu option in the upper left of the page), which are matched with high-resolution DEMs derived from stereo image pairs. This dataset includes all of the Apollo landing sites and dozens of other locations of interest.
